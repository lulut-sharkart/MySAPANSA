    Sinergi dan Akses Portal Aktif Guru-Wali Murid Ngandul 1

    Petunjuk penggunaan

    1. Masukkan NIS/NISN (siswa), NIP (guru), atau username (admin), lalu password. Peran dikenali otomatis.
    2. Pilih menu di sidebar kiri. Di HP, buka lewat tombol Menu.
    3. Isi kolom di atas tabel, lalu pilih Tambah. Gunakan pencarian dan filter untuk menyaring data.
    4. Pilih Cetak, PDF, DOCX, RTF, XLSX, CSV, atau JSON untuk mengunduh data.
    5. Admin: gunakan Absensi otomatis untuk mengisi kehadiran semua pengguna sekaligus, dan menu Database untuk ekspor/impor.
    6. Ubah warna dan logo watermark di Pengaturan.
